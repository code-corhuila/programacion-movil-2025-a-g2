# Documentación - App Móvil Carrito de Compras

## Descripción
Este directorio contiene la documentación completa para la aplicación móvil de carrito de compras. Aquí encontrarás guías, referencias y ejemplos para ayudarte a entender y utilizar el proyecto.

## Contenido
- **Guía de Instalación**: Instrucciones detalladas para instalar y configurar el proyecto.
- **Referencia de API**: Descripción de los endpoints disponibles en el backend.
- **Guía de Usuario**: Instrucciones para los usuarios finales sobre cómo utilizar la aplicación.
- **Guía de Desarrollador**: Información para desarrolladores que deseen contribuir al proyecto.

## Estructura
- `instalacion.md`: Guía de instalación y configuración.
- `api.md`: Referencia de API.
- `usuario.md`: Guía de usuario.
- `desarrollador.md`: Guía de desarrollador.

## Contribuir
1. Hacer un fork del repositorio.
2. Crear una nueva rama:
    ```bash
    git checkout -b feature/nueva-documentacion
    ```
3. Realizar los cambios y hacer commit:
    ```bash
    git commit -m "Agregar nueva documentación"
    ```
4. Hacer push a la rama:
    ```bash
    git push origin feature/nueva-documentacion
    ```
5. Crear un Pull Request.
