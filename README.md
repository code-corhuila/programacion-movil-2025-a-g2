# Rama Develop - App Móvil Carrito de Compras

## Descripción
La rama `develop` contiene el desarrollo principal de la aplicación móvil de carrito de compras. Esta rama incluye los siguientes componentes:

- **Backend**: Proporciona una API para gestionar productos, usuarios y pedidos.
- **Frontend**: Proporciona una interfaz de usuario para que los clientes puedan navegar y comprar productos.
- **Database**: Contiene la configuración y los scripts necesarios para gestionar la base de datos.
- **Docs**: Contiene la documentación completa del proyecto.

## Base de la HU 04
Esta rama está construida sobre la Historia de Usuario 04 (HU 04), que define los requisitos y funcionalidades principales del proyecto.

## Estructura del Proyecto
- `backend/`: Código fuente del backend.
- `frontend/`: Código fuente del frontend.
- `database/`: Configuración y scripts de la base de datos.
- `docs/`: Documentación del proyecto.
