# Frontend - App Móvil Carrito de Compras

## Descripción
Este proyecto es el frontend para una aplicación móvil de carrito de compras. Proporciona una interfaz de usuario para que los clientes puedan navegar y comprar productos.

## Tecnologías
- React Native
- Redux
- Axios

## Instalación
1. Clonar el repositorio:
    ```bash
    git clone https://github.com/usuario/repositorio.git
    ```
2. Navegar al directorio del frontend:
    ```bash
    cd frontend
    ```
3. Instalar las dependencias:
    ```bash
    npm install
    ```

## Configuración
1. Crear un archivo `.env` en el directorio raíz con las siguientes variables:
    ```env
    API_URL=http://localhost:3000
    ```

## Uso
1. Iniciar la aplicación:
    ```bash
    npm start
    ```
2. La aplicación estará disponible en el emulador o dispositivo conectado.

## Funcionalidades
- Navegar por los productos
- Agregar productos al carrito
- Realizar pedidos
- Iniciar sesión y registrarse
